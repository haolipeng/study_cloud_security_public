# Nozomi 四类告警检测项评估

**评估前提**：

- 数据来源：仅旁路网络镜像流量
- 检测能力：
  - Suricata规则引擎
  - 后期Zeek行为引擎
  - IEC61850 MMS解析
  - IEC61850 GOOSE解析
- 不依赖：
  - 主机信息
  - Agent端侧信息（如usb插拔信息）
  - 文件
  - 设备日志

### 1.1 MMS Write 配置对象修改

对应：

> 检测 MMS Write 配置对象、服务访问行为

旁路可以看到：

```
工程师站
    |
    | MMS Write
    |
IED
```

解析：

```
MMS WriteRequest

ObjectReference:
IED1/LLN0.xxx.yyy

Value:
xxx
```

可以判断：

- 哪个IED被修改
- 修改哪个对象
- 修改前后值（如果有上下文）
- 来源设备

例如：

```
Client:
10.1.1.100

Operation:
Write

Target:
IED01/PTOC1.StrVal

Value:
500
```

可以产生：

```
IEC61850 Setting Change
```
